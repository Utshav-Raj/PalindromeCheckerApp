# Palindrome Checker Application 🚀

## 🎯 Project Objective
The objective of the **Palindrome Checker App** is to design and implement a console-based Java application that validates whether a given string is a palindrome under different conditions. This project serves to strengthen core programming fundamentals and data structure concepts.

---

## 🛠️ Project Procedure
To ensure a clean and organized development process, the following steps were taken:
1. **Repository Setup**: Initialized a Git repository and organized the folder structure.
2. **Environment Configuration**: Set up a `.gitignore` to exclude IDE-specific files (`.idea/`).
3. **Incremental Development**: Following a Use Case (UC) driven approach to build features one by one.
4. **Compilation & Testing**: Using `javac` for compilation and `java` for JVM execution to verify each module.

---

## 🔄 Project Flow
The application follows a modular flow:
1. **Startup**: JVM invokes the entry point.
2. **Initialization**: Displaying application metadata (Name, Version).
3. **Input Handling** (Planned): Capturing user strings for validation.
4. **Logic Execution** (Planned): Processing strings to check for palindrome properties.
5. **Output**: Displaying results to the console.
